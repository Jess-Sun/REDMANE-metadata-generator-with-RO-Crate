# Test WGS Dataset

This directory contains synthetic (dummy) data used to test the file searching and metadata generation script.   
config.json supplies the information needed to run the metadata generator on a specific dataset.

## Synthetic data
Generated from: https://github.com/eamandaa/Workflow-team-Summer-25/blob/main/Project%202/Project%202.ipynb  
Modification were made to make the file sizes smaller for space efficiency.  
patient_sample_mapping in the config.json is derived from the patient_sample_mapping.csv generated by the notebook.  
While SampleID follows XY###, file names may be XY###-AGRF.fastq or other file extensions.  
There should be 10 files each in the Raw, Processed and Summarised folders.

## config.json

The name is expected to be config.json. It needs to be placed in the target directory supplied as input argument.  
e.g. Here config.json for the imaging dataset is found in ./test_WGS
`    python update_local_v1.py ./test_WGS`

Contains:
```
{
  "directory": "test_WGS",              # Expected directory
  "raw_file_extensions": [              # File extensions of interest
    ".fastq"
  ],
  "processed_file_extensions": [
    ".bam"
  ],
  "summarised_file_extensions": [
    ".vcf"
  ],
  "patient_sample_mapping": {           # Patient to Sample mapping for that dataset
  "XY001": "PatientID001_DiseaseX",
  "XY002": ...
}
}
```
Currently the custom config.json file is created manually.  
In future the config.json should be automatically generated and be downloaded from the data registry website after the researcher creates a new dataset and enters file extensions of interest.
